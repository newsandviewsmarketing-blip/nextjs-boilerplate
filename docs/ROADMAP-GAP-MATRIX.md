# VetConnect roadmap gap matrix

This file prevents a release package from being labelled "complete" when a broader product-roadmap item is still future work.

## Implemented/represented in the current source

- Supabase email authentication and role-based registration
- public veterinarian, professional, clinic, laboratory, company, product and job directories
- company workspace and product submission/editing
- professional/company/lab verification queues
- product regulatory review separation
- public job listings and job applications
- administrator hierarchy and permission checks
- admin users, product lifecycle, review queue and audit log
- recoverable product archive and restricted permanent deletion
- RLS-oriented database design and audit records
- responsive public UI baseline
- SEO baseline added in this consolidated release candidate

## Partially implemented / requires live database and role acceptance testing

- company/team permissions across all intended business modules
- job matching and candidate preference data model
- complete HR/candidate workflow
- notification delivery
- full taxonomy-management user interface
- complete regulatory/document-management user interface
- complete company branches/team UI

## Not represented as complete production modules in this source

- animal/patient records and full clinical encounter history
- appointment availability/calendar and double-booking prevention
- veterinarian-authored clinical-summary/prescription document workflow
- full learning/course authoring and delivery workflow
- full VNV/knowledge ingestion workflow
- configurable advertising-management user interface and campaign analytics
- future mobile application

These roadmap areas should be implemented as controlled later phases rather than simulated with disconnected static screens.
